# 0010: Quadro P2000 for Jellyfin and Tunarr
Status: accepted

## Context

Jellyfin, the media server, and Tunarr can both use a GPU for video work.

## Decision

poseidon has an NVIDIA Quadro P2000 (5 GB), passed through to the Jellyfin
and Tunarr containers. I used it because it was available hardware.

## Alternatives considered

None recorded.

## Consequences

- Unraid needs the NVIDIA driver plugin.
- Jellyfin gets the GPU as a Docker device request, and Tunarr through the
  NVIDIA container runtime.
